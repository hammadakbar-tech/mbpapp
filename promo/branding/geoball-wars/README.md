# GeoBall Wars: channel branding

| File | Size | Use |
|---|---|---|
| `geoball-wars-logo.png` | 1024×1024 | **Profile picture** (YouTube, TikTok, Facebook). Circle-safe: everything sits inside the gold ring |
| `geoball-wars-icon.png` | 1024×1024 | Text-free version for tiny placements: watermark, favicon, video end-screen corner |
| `geoball-wars-banner.png` | 2560×1440 | **YouTube channel banner.** Title, tagline and logo sit inside the 1546×423 safe area that shows on every device. The ring of country balls appears on TV and desktop |
| `preview-circle-sizes.png` | | How the logo looks in YouTube's circle crop at 240 / 120 / 64 / 40 / 24 px |

**Design:** an angry Earth countryball (real continent outlines, centred on Australia and Asia, the channel's core audience) over crossed swords and a gold starburst, with "GEOBALL" in gold and "WARS" on a red ribbon. Gold, red and navy match the episode thumbnails.

**Uploading:**
- **YouTube:** Customization → Branding → Picture (logo) and Banner image (banner). Optional video watermark: the icon.
- **TikTok and Facebook:** use the logo as the profile picture. They crop to a circle, and the design is circle-safe.

Rebuild: `python3 logo.py <data_dir> <out_dir>` (needs the shared promo modules, Natural Earth `countries_50m.geojson`, and flags).
